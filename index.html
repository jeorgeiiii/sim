What this page does not show

The flows above are read from folder names, file names and the repo's own rules, not from stepping through every function. Not covered: Copilot and Mothership internals, billing, knowledge-base ingestion, the MCP server, and enterprise features in ee/. For file-level links, open the generated code graph.
